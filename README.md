# Dushi Vacation Store · mockup del sitio

Mockup estático (HTML/CSS/JS, sin dependencias) del sitio de Dushi Vacation Store, siguiendo el Manual de marca V3.

- `index.html`: la página completa.
- `assets/`: logos, fotos ilustrativas (IA) y el video del hero (`dushi-hero.mp4`, generado con Higgsfield).

Para verlo: abre `index.html` en el navegador (o `python3 -m http.server` en esta carpeta).

Precios, marcas y promos son de ejemplo.
